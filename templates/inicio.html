Sistema IDS para detección de tráfico malicioso

Plataforma web basada en Machine Learning para analizar archivos CSV de tráfico de red y detectar posibles ataques DDoS.

El sistema permite subir archivos compatibles con CIC-IDS2017 y analizarlos mediante diferentes modelos supervisados, como Random Forest, Decision Tree y KNN.
